# 안전보건교육(하반기·사무직) 최종평가 답안 정리

- 개인 참고용. 확장(`extension/`)에 포함되지 않음 → 배포 zip에 안 실림.
- 보기 순서는 응시마다 섞일 수 있어 **정답 지문**으로 적음(번호는 그때 화면 기준 참고값).
- 문제은행이 세트별로 도는 것으로 보임 — 아래에 없는 문제가 나오면 제출 후 결과창 해설로 확인해 추가.

## 안전 수칙·표지

- **안전보건표지 종류로 "틀린" 것** → **휴식표지** (표지 4종 = 금지·경고·지시·안내)
- **사무직 근로자 정기교육 시간으로 옳은 것** → **매반기 6시간 이상**
- **감전 위험 작업에 착용할 보호구** → **절연용 보호구**

## 직장 내 괴롭힘

- **'피해자' 설명으로 "틀린" 것** → **"정규직만 피해자로 인정된다"** (고용형태 무관, 계약직·기간제 포함)
- **비밀 누설 금지 위반 과태료** → **500만원 이하**
- **분쟁 해결 방법으로 "틀린" 것** → **"고용노동부 신고 시 우편 접수만 가능하다"** (방문·우편·온라인 모두 가능)

## 근로자 건강진단·건강관리

- **배치 전 건강진단 설명으로 "틀린" 것** → **"정기적으로 건강 상태 추이를 확인하기 위한 검사이다"** (그건 정기건강진단)
- **건강관리 판정 구분으로 "틀린" 것** → **"A는 평가가 곤란하거나 질병이 의심되는 근로자"** (A=사후관리 불필요한 정상, 그 서술은 R 판정)
  - 참고: C1=직업성 질병 요관찰, C2=일반질병 요관찰, D1=직업병 유소견
- **건강 상태가 직무 만족도에 미치는 영향으로 "옳은" 것** → **"건강한 근로자는 직무에 더 만족하고 이직률을 낮춘다"**
- **근로자 운동 관리의 '신체적 효능'에 해당하지 "않는" 것** → **우울감 예방** (그건 정신적 효능)
- **벤젠 작업 특수건강진단 주기** → **6개월** (※ 확신 낮았던 항목 — 결과창 해설로 재확인 권장)

## 직업병

- **'직업력 조사' 내용으로 "틀린" 것** → **"동료 근로자들의 역학 자료"** (본인 작업내용·근무기간·흡연/음주가 항목)
- **직업병 분류 중 '근골격계 질환'에 해당하는 것** → **손목터널증후군** (천식·알레르기성 피부염·소음성 난청은 아님)
- **직업병의 특징이 "아닌" 것** → **"개인의 성격적 요인이 주된 원인이다"** (작업환경 외적 요인 + 내재 요인 복합)

## 근골격계 질환 예방·관리

- **허리를 비트는 자세일 때 대처로 "틀린" 것** → **"허리가 한쪽으로만 비틀리도록 작업한다"**
- **반복 작업 시 대응 전략으로 "틀린" 것** → **"손목을 최대한 꺾어 힘을 분산시킨다"**
- **근골격계질환의 심리적·사회적 요인이 "아닌" 것** → **흡연·음주** (직무스트레스·만족도저하·우울불안은 심리사회적)

## 뇌·심혈관질환

- **위험요인 중 '환경적 요인'에 해당하지 "않는" 것** → **사회적 고립** (대기오염·소음·기후변화는 환경적)
- **일상 속 피로 관리 방법으로 "틀린" 것** → **"취침 전 1시간은 활동적으로 움직이기"** (취침 전엔 안정)
- **관상동맥이 좁아져 심근에 혈액이 일시적으로 부족해지는 질병** → **협심증**
