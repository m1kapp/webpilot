Webwing 설치

로그인된 근태·경비 화면을 사이드 패널에서 한눈에
① 확장 파일(zip) 다운로드
눌러도 안 받아지면 우클릭 → "다른 이름으로 링크 저장"
설치 3단계

크롬에 추가하기

  1. 받은 webwing-extension-0.1.0.zip을 압축 해제합니다(더블클릭).
  2. 주소창에 chrome://extensions 입력 → 오른쪽 위 개발자 모드 켜기.
  3. 압축해제된 확장 프로그램을 로드 → 방금 푼 webwing-extension-0.1.0 폴더 선택.
폴더를 옮기거나 지우면 확장이 사라집니다. 다운로드 폴더에 그대로 두세요.

쓰는 법

  1. 아래 서비스에 평소처럼 로그인해 둡니다.
    타임인아웃비즈플레이Flow
  2. 크롬 툴바의 Webwing 아이콘(퍼즐 아이콘 안에 있으면 고정) 클릭 → 오른쪽 패널이 열립니다.
  3. 보고 싶은 자동화를 누르면 조회가 시작됩니다. 아이디·비밀번호는 저장하지 않습니다.

업데이트

새 버전 안내가 오면 zip을 다시 받아 같은 폴더에 덮어쓰고, chrome://extensions에서 Webwing 카드의 새로고침(↻)을 누르면 됩니다.

② (심사 통과 후) 웹스토어에서 원클릭 설치 — 준비 중
정식 스토어 링크가 나오면 이 버튼이 활성화됩니다. 그전까지는 위 zip 방식으로 쓰세요.
문의: 배포 담당자(사내 공지 참조) · 개인정보는 기기에만 저장, 외부 전송 없음
