Webwing 개인정보 처리방침

최종 수정: 2026-08-28 · 사내 배포용 크롬 확장 프로그램

1. 개요

Webwing은 사용자가 이미 로그인한 사내 업무 시스템(타임인아웃·비즈플레이·Flow·사이버연수원)의 본인 데이터를 브라우저 사이드 패널에 모아 보고 정리하도록 돕는 도구입니다. 별도 서버가 없으며, 모든 처리는 사용자의 브라우저 안에서 이루어집니다.

2. 수집·저장하는 정보

  • 사용자가 선택한 조회 설정(연도·월)과 사이버연수원 사번, Flow API 키는 chrome.storage를 통해 사용자 기기에만 저장됩니다.
  • 근태·경비·교육 데이터는 화면 표시를 위해 일시적으로 읽을 뿐, 확장 프로그램이 어디에도 저장하거나 전송하지 않습니다.

3. 외부 전송

Webwing은 수집한 어떤 데이터도 개발자나 제3자에게 전송하지 않습니다. 확장 프로그램 자체 서버가 없습니다. 네트워크 통신은 사용자가 로그인한 각 서비스의 도메인(타임인아웃·비즈플레이·Flow·사이버연수원)에 대해서만, 사용자 본인 데이터를 조회하기 위해 발생합니다.

4. 권한 사용 이유

  • storage — 조회 설정·사번·API 키를 기기에 저장
  • scripting — 사용자가 로그인한 페이지에서 본인 데이터를 읽어 화면에 표시
  • tabs — 조회용 배경 탭을 열고 닫음
  • sidePanel — 사이드 패널 UI 표시
  • webNavigation — 일부 화면(카드영수증 등)의 내부 프레임 탐색
  • 호스트 권한 — 데이터 출처인 각 서비스 도메인에서만 동작

5. 원격 코드

외부에서 코드를 내려받아 실행하지 않습니다. 모든 로직은 확장 패키지에 포함되어 있습니다.
